# Projet Guilde

## Description
Dans le cadre de ma formation en Développeur web full stack, j'ai décider de créer un projet de site web rassemblant deux de mes passions, le jeux de rôles et les jeux de stratégies. Cela c'est traduit par un projet de site web de gestion d'une compagnie d'aventuriers, avec un système de jeu de stratégie au tour par tour.
